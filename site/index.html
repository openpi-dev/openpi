01 理念 默认轻，按需强

复杂度只在值得的时候出现。

普通编码任务继续走 Pi 原生路径：read、bash、edit、write，完整历史与会话压缩。 任务一旦需要长期进程、并行调研、隔离实现或跨回合推进，高级能力仍然完整存在—— 直接说出需求，OpenPI 就在当轮加载对应能力。轻路径不缴复杂度税，重任务不缺工程能力。

0OpenPI 工具 · 本轮

Pi 原生，始终存在本轮加载资源真实存在后才出现只讨论「子代理是什么」不会加载；否定与条件句保持 fail closed。想让模型自己判断，可在 /openpi-setup 开启 adaptive——只常驻一个小型 openpi_load_tools 网关。

02 能力 三条执行路径

一个工作台，
而不是一组互不协调的插件。

i. Background Terminal
长期进程不阻塞对话

开发服务器、监听任务、长测试放进后台。独立日志、超时与完成通知；bg_kill 终止整个进程树，会话结束时有界清理。

ii. Subagent
隔离上下文，不另起系统

每个子代理是独立的进程内 Pi 会话，默认继承 Provider 与模型；可 check、wait、cancel，也能继续对话。并行写入用独立 worktree，自定义角色的显式工具列表由运行时强制。

iii. Workflow
多阶段编排，有证据有产物

pipeline / parallel、结构化输出、结果交接、调用账本与安全重放。一次调用是可审计的生命周期，而不是「进程退出 0」。

工作项与目标跨回合的工作清单与持续自主目标，完成前要求证据审计
计划模式只读调研与批准门禁，计划就绪后才准备实施
上下文切换同一会话的阶段切换，用自包含简报替换旧噪音
可观测性状态栏、仪表盘、产物与完成通知统一呈现状态
03 界面 终端里的样子

看得见，才停得住。

终端里，状态压进一行，工具结果折叠成语义摘要；需要看清多个项目的对话与工具轨迹时，输入 /web 打开本机 Web 工作台。两边使用同一套能力，会话彼此独立。

03.1紧凑工具结果每个动作一行语义摘要：目标、状态、关键规模；Ctrl+O 随时展开完整证据。
03.2下一步建议运行结束后，空输入框出现一条暗色幽灵建议；→ 只填入不提交。默认关闭，写入会话之外。
03.3自定义角色全局 ~/.pi/agent/agents/*.md 或项目 .pi/agents/*.md 覆盖内置角色，可指定独立模型与推理档位。
03.4可定制状态栏模型、上下文、Git、目录压进一行；powerline、紧凑或多行布局，由 /openpi-setup 调整。
03.5本地 Web 工作台只监听 loopback；查看已保存的 Prompt、工具参数与结果轨迹。不接管、不写入终端里正在进行的对话；也可用 openpi web /path/to/repo 单独启动。
03.6结构化搜索与只读 Gitfd、rg、git_show / git_diff / git_log 以结构化参数调用，不拼接 Shell，输出有界。
04 运行模型 任务应该去哪里

Pi 始终拥有主会话。

终端、子代理与工作流是三条执行路径；工作项、目标与上下文切换保持连续性；状态栏、仪表盘与清理逻辑负责观察和控制。增强 Pi 的深度，不扩大隐式权限。

长期进程→后台终端
自包含、可继续对话的委派→子代理
多阶段、依赖、扇出与综合→工作流
跨回合工作项→Tasks
持续自主目标→Goal
同一会话的阶段切换→上下文切换
真正跨顶层 Session→pi-intercom（按需安装）
05 工作流 不只是并行

把一次调用，拆成
可以审计的生命周期。

05.1

结果交接与派生图谱

成功调用返回不透明引用 ref，后续调用通过 inputs 显式接收上游结论，并标记为不可信数据。产物从引用派生只读图谱，可观察血缘，不参与调度。

05.2

调用账本

每次 agent() 独立记录意图、准入与执行状态。崩溃后未终结的调用恢复为 uncertain——不猜成成功、失败或安全重试。

05.3

安全重放

resume_from_run_id 只重放可证明只读且指纹未变的调用。指纹覆盖提示词、结构、模型、仓库状态与信任决策；不确定就真实执行。

05.4

Worktree 交接

清理隔离 checkout 前，原子保存 patch、分支 / HEAD、未跟踪文件清单与清理回执。状态不明就保留现场，不自动 merge、apply 或强删。

06 安全边界 运行时约束

安全不是一段提示词，
而是运行时约束。

completed子会话执行与结果制品都成功
failed保留原生 Provider 错误与原始输出
cancelled显式取消与 Session 清理都有时间上限
uncertain崩溃后仍未终结的调用——不猜成成功、失败或可安全重试
child.recursion禁止。子代理与工作流子会话不获得父级编排、交互与状态工具
agent_type.tools运行时强制白名单；声明不能突破父级黑名单
tools.preflight未知、损坏、错名或最终未注册的工具在首个 Token 前失败
workflow.sandbox无文件、网络、进程、import、eval 或计时器接口
replay只有可证明只读、指纹完整且无不安全重叠的调用才缓存
worktree.cleanup未知即保留；状态不确定时绝不删除现场
terminal.output控制字符与超长内容在渲染边界清洗、限长
shutdown终端、子代理、工作流都有有界取消、清理与唯一终态
model.usage下一步建议默认关闭；自适应模式仅在显式开启后可自主加载能力
07 命令速查 一个配置入口

一个配置入口，
一组可检查的控制面。

/openpi-setup [自然语言]
查看或修改统一配置；可选择安装会话间通信
/web
前台运行独立 Web 工作台；Ctrl+C 回到 Pi
/ps
查看、跟踪与终止后台终端
/subagents · /btw
管理子代理 / 在旁路上下文中提问
/workflows
查看阶段、代理、图谱与产物；可停止运行
/tasks · /goal
查看工作项 / 管理持续目标
/plan [目标]
只读调研；计划就绪后显式选择实施方式
/context-pivot <阶段>
在同一会话中压缩旧阶段并继续
/sessions
搜索、预览与切换会话
/cron …
为当前会话安排一次或周期性 Prompt
